# Coding standards

- Atomic Design layering is mandatory — reuse an existing atom/molecule
  before hand-rolling a new one; place new components at the correct
  level (see architecture.md).
- Only `organisms/*` and `app/*` call generated hooks or hold state —
  atoms/molecules stay pure/props-driven so they're trivially testable
  and reusable.
- Never hand-edit `src/lib/api/generated/**` — it's regenerated by
  `npm run generate` and any manual edit is silently lost.
- `"use client"` only on the components that actually need
  interactivity/hooks (`providers.tsx`, the organisms) — `page.tsx`
  stays a Server Component.
- No comments that restate the code — same bar as the backend
  boilerplates.
